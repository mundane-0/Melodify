# Melodify

Lecteur de musique de bureau (pywebview + Flask) : bibliothèque locale + YouTube,
paroles synchronisées, visualiseur, statistiques d'écoute, Discord Rich Presence,
plateau système, et interface entièrement personnalisable.

## Installation
```bash
chmod +x install.sh
./install.sh            # ajoute --no-system-deps pour sauter les paquets système
